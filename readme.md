# FirmwareFetcher

Neon + Cloudflare Workers + Telegram bot

This project does not contain any secrets required to call the official server.

To run locally, set the following environment secrets:
`HUAWEI_DEVICE_ID`, `HUAWEI_DEV_CERT`, `HUAWEI_KEY_ATT`, `HONOR_DEVICE_ID`, `HONOR_DEV_CERT`, `HONOR_KEY_ATT`

Then `npm run dev`
